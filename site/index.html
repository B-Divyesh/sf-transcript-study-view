Private by construction

Captured text lives only for the browser session. Highlights and reading preferences are stored locally. There are no accounts, analytics, remote transcription calls, or media downloads.

Step-by-step Chromium install
  1. Download and unzip the package.
  2. Open chrome://extensions or edge://extensions.
  3. Turn on Developer mode.
  4. Choose “Load unpacked” and select the chrome-mv3 folder.
  5. Pin Study View, open a captioned talk, and select the extension.
