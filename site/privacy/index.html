Privacy, in plain language.

Transcript Study View is designed so the reading activity it enables does not need to become someone else’s data.

What the extension reads

When you activate the extension on a supported YouTube video or TED talk, it reads the official timed transcript already exposed on that page to your browser. It does not download video or audio, bypass access controls, or create a transcript when the source does not provide one.

What stays on your device

  • Captured transcript text is held in browser session storage and is cleared with the browser session.
  • Highlights and reading preferences are stored in extension-local browser storage so they remain available on that device.
  • Browser text-to-speech uses voices provided by your browser or operating system. Study View does not send text to our servers.

What we collect

Nothing. Version 1.0 includes no account, analytics, advertising, telemetry, remote API, or tracking pixel. The website does not set cookies. A deployment host may retain short-lived security logs such as an IP address and requested path; the extension neither receives nor uses them.

Permissions

The extension requests access to the active tab, local storage, and supported YouTube and TED pages. Active-tab access lets it read a transcript only when you invoke it. Storage keeps your settings and highlights. Site access lets timestamp links return to the original player.

Deleting your data

Remove individual highlights inside Study View. Uninstalling the extension removes all extension-local highlights and preferences. Ending the browser session removes captured transcript sessions.

Contact and changes

Questions or privacy concerns can be filed in the project’s public issue tracker. Material changes will be dated on this page and described in release notes.
